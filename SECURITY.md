# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.4.x   | :white_check_mark: |
| < 0.4   | :x:                |

## Reporting a Vulnerability

We take the security of Ohnana seriously. If you discover a security vulnerability, please follow these steps:

1. **Do not** open a public issue
2. Email your findings to devlemonsalve@gmail.com
3. Include detailed steps to reproduce the vulnerability
4. Allow up to 90 days for responsible disclosure

### What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

### What to Expect

- Acknowledgment of your email within 48-72 hours
- Regular updates on the progress
- Credit for the discovery (if desired) when the issue is resolved

## Security Best Practices

When using Ohnana in production:

- Keep dependencies up to date
- Use environment variables for sensitive configuration
- Enable rate limiting for public-facing APIs
- Implement proper authentication and authorization
- Review security headers in production deployments

Thank you for helping keep Ohnana and its users safe!
